# Starcatcher

Starcatcher ist ein kleines Browser-Spiel, das du lokal im Browser spielen kannst. Steuere dein Lichtschiff, fange Sterne und weiche gefährlichen Meteoriten aus.

## Installation & Start

1. Lade den gesamten Ordner auf deinen Rechner (z. B. per `git clone`).
2. Öffne die Datei `index.html` in einem modernen Browser (Chrome, Firefox, Edge, Safari).

Es ist kein zusätzlicher Build-Schritt nötig.

## Steuerung

- **Links/Rechts:** Pfeiltasten oder `A`/`D`
- **Neustart:** Klick auf „Erneut spielen“ oder Leertaste, nachdem das Spiel beendet wurde

## Spielprinzip

- Sammle goldene Sterne, um Punkte zu erhalten.
- Vermeide rote Meteoriten – jeder Treffer kostet ein Leben.
- Erreiche neue Level, um Bonus-Leben zu verdienen. Mit jedem Level steigen Geschwindigkeit und Schwierigkeit.

Viel Spaß beim Fangen der Sterne!
